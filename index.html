ESP32-TOOLS

Multiferramenta de segurança WiFi + Bluetooth para ESP32.
Grave no seu aparelho direto do navegador.

⚡ Instalar o firmware

Conecte o ESP32 no USB e clique. Sem instalar nada.

⚠️ Navegador não compatível.
Use Chrome, Edge ou Opera no computador (não funciona no celular). ⚠️ A página precisa estar em HTTPS pra gravar.
  • Use Chrome / Edge / Opera no computador (o celular não grava)
  • Conecte o ESP32 via USB e feche o Monitor Serial / Arduino IDE
  • Clique em Instalar e escolha a porta COM
  • Se travar em "Connecting…", segure o botão BOOT da plaquinha
✨ Novidades deste fork
  • Injeção 802.11 automática — Deauther, Beacon Spam e Karma funcionam ao compilar (sem patch manual)
  • Contadores honestos — só contam pacotes que o rádio realmente transmitiu
  • BT Disruptor honesto — removido o modo "L2CAP" falso; nomes refletem o que faz de verdade
  • Karma sem promessa falsa — o aviso descreve o comportamento real
  • Documentação técnica completa — arquitetura, fluxos e tabela de honestidade

O que ele faz

📶 WiFi
Scanner, Evil Portal, Deauther, Beacon Spam, Probe Sniffer, Packet Monitor
🔵 Bluetooth
BLE Scanner, BLE Spam (Apple/Samsung/MS/Google), BLE Adv
📡 Rádio 2.4GHz
Analisador de espectro e transmissor (via NRF24)
🧭 Sistema
Relógio/Clima, System Info, configurações — tela colorida + 3 botões
